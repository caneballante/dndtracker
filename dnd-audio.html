DnD Tracker Help & Cheat Sheet

                    
                  

                  

                    

                      
Fast Flow

                      
Use this mental model: Campaign = canon, Session = live recording, History = repair and post-processing.

                      
    
                        
  1. Open or create a campaign.
    2. 
                        
  2. On Session, confirm the campaign context and participant roster.
    3. 
                        
  3. Press Start to record.
    4. 
                        
  4. Press Stop when the game ends.
    5. 
                        
  5. Go to History to review transcript, notes, summary, and narrative for that campaign.
    6. 
                        
  6. Use Campaign to update the canonical roster, summaries, and prep for next time.
    7. 
                      

                    


                    

                      
Session Page

                      
    
                        
  • Session Name labels one session. It does not change the campaign name.
    • 
                        
  • Campaign Context previews the campaign data that will be used for notes and summaries.
    • 
                        
  • Chunk length (minutes) controls how often live audio is cut into uploaded chunks during recording.
    • 
                        
  • Session Participants is the roster snapshot for this one session. Load from the campaign, then adjust for absences or guests.
    • 
                      

                    


                    

                      
History Page

                      
    
                        
  • Rebuild Notes + Summary now uses the settled default notes window automatically.
    • 
                        
  • Use Notes Lab if you want to experiment with different chunk windows on a smaller slice before changing anything else.
    • 
                        
  • Backfill Missing Audio retranscribes saved audio chunks that exist on disk but are missing from the transcript, such as chunks recorded while you were offline.
    • 
                        
  • Retranscribe Chunk Range replaces existing transcript entries for a specific saved audio slice when you want to test a different transcription model or repair a known section.
    • 
                        
  • Rebuild Clean Transcript rewrites the readable transcript from the raw transcript entries. It does not recover missing audio on its own.
    • 
                        
  • Rebuild Notes + Summary regenerates DM notes and the rolling notes summary from the transcript.
    • 
                        
  • Generate Game Summary and Generate Narrative are best run after transcript and notes look correct.
    • 
                      

                    


                    

                      
Recommended Repair Order

                      
    
                        
  1. If transcript chunks are missing, run Backfill Missing Audio first.
    2. 
                        
  2. If the transcript is present but messy, run Rebuild Clean Transcript.
    3. 
                        
  3. Run Rebuild Notes + Summary after transcript recovery or cleanup.
    4. 
                        
  4. Then regenerate Game Summary or Narrative if needed.
    5. 
                      

                    


                    

                      
What To Edit Where

                      
    
                        
  • Use Campaign for the party roster, campaign summary, previous session summaries, and DungeonMaker JSON.
    • 
                        
  • Use History to inspect and regenerate one session’s outputs.
    • 
                        
  • If a generated output is wrong, correct campaign canon on the Campaign page so the next session starts from the right context.
    •

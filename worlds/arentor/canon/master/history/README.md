# Arentor World Canon History

World Canon is reusable baseline setting truth shared by campaigns. Campaign Continuity records campaign-specific changes layered over World Canon. Adventure References are reusable prepared/local material and cannot override World Canon. Session Evidence proves what actually occurred during play.

`candidates/` contains reviewed but unpromoted Master Canon, `source/` contains provenance material, and `history/` will contain superseded approved snapshots after future promotion.
